# Site skins

The intro screen and the home page show a live 3D player (skinview3d).

| File | Used for |
|---|---|
| `skin-1.png` | The player on the intro screen, before anyone clicks |
| `skin-2.png` | The player after the click, and on the home page (wearing the Gold halo) |

Use standard 64×64 Minecraft skin PNGs; slim (Alex-style) arms are detected automatically. Until these files exist, the site shows plain stand-in skins.

The halo comes from `docs/models/gold-halo/`, a copy of the mod's own preset files, placed the same way the preset places it in game.
