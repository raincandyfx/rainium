Latest release for Minecraft 26.3

Get RainiumFree and open source

  1. Install FabricFabric Loader and Fabric API for 26.3.
  2. Add RainiumDrop the .jar into .minecraft/mods.
  3. Press KThe editor opens in game.

After that, updates install themselves.

Guide

  1. 1

    Open the editor

    Press K in game.

  2. 2

    Try the halo

    Switch on Gold halo in the layer list.

  3. 3

    Add your model

    Drop it in the rainium folder, then pick it on the Add tab.

  4. 4

    Make it yours

    Texture, glow, size, sway and who wears it.

Hover any setting for help. Ctrl+Z undoes anything.
