# Site pictures

Drop a picture into this folder with one of the names below and the site shows it in place of the matching placeholder. No code changes needed. PNG at the listed size or larger works best; it is cropped to fill the frame.

| File | Page | Shows | Shape |
|---|---|---|---|
| `hero.png` | Home | Your character art: a player wearing Rainium cosmetics, cut out on a transparent background. It fills the left of the menu screen, like the character in a game's pause menu | 3:4 portrait, e.g. 1200×1600, PNG with transparency |
| `materials.png` | Features | A model split into its material parts in the layer list | wide, e.g. 1200×600 |
| `textures.png` | Features | One model, three textures side by side | wide |
| `glow.png` | Features | A halo glowing in a dark cave | wide |
| `players.png` | Features | Cosmetics on friends and an armor stand | wide |
| `guide-editor.png` | Guide, step 1 | The editor open over the game | 16:10 |
| `guide-halo.png` | Guide, step 2 | The example halo switched on | 16:10 |
| `guide-import.png` | Guide, step 3 | Importing a model with the live preview | 16:10 |
| `guide-edit.png` | Guide, step 4 | The Edit tab with Look and Placement | 16:10 |
| `particles.png` | Particles | Embers trailing behind a running player | 4:5 portrait |

To use a different format (such as `.jpg` or `.webp`), change the `data-img` value on that placeholder in `docs/index.html`.
