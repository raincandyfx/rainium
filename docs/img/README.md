# Site pictures

Drop a picture into this folder with one of the names below and the site shows it in place of the matching placeholder. No code changes needed. PNG at the listed size or larger works best; it is cropped to fill the frame.

| File | Page | Shows | Shape |
|---|---|---|---|
| `hero.png` | Home | A player wearing Rainium cosmetics, cut out on a transparent background (it sits over the menu screen like a game character) | 3:4 portrait, e.g. 1200×1600, PNG with transparency |
| `features-hero.png` | Features (top) | Wings with glowing trim, worn on a player at night | 4:3, e.g. 1600×1200 |
| `materials.png` | Features | A model split into its material parts in the layer list | square, e.g. 1000×1000 |
| `textures.png` | Features | One model, three textures side by side | square |
| `glow.png` | Features | A halo glowing in a dark cave | square |
| `players.png` | Features | Cosmetics on friends and an armor stand | square |
| `download-editor.png` | Download | The Rainium editor, first launch | 16:10, e.g. 1600×1000 |
| `guide-editor.png` | Guide, step 1 | The editor open over the game | 16:10 |
| `guide-halo.png` | Guide, step 2 | The example halo switched on | 16:10 |
| `guide-import.png` | Guide, step 3 | Importing a model with the live preview | 16:10 |
| `guide-edit.png` | Guide, step 4 | The Edit tab with Look and Placement | 16:10 |
| `particles.png` | Particles | Embers trailing behind a running player | 4:3 |
| `models-import.png` | Models | The Add tab previewing an imported model | 16:10 |

To use a different format (such as `.jpg` or `.webp`), change the `data-img` value on that placeholder in `docs/index.html`.
